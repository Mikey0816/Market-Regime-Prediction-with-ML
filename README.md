# Market-Regime-Prediction-with-ML

This project attempts to predict market regimes using machine learning. It uses various price and volume features to predict whether the regime of the next day will be bear or bull. This is used to hold or sell accordingly. We utilize a logistic regression model and a random forest model, being compared against a buy-and-hold strategy in the S&P 500. This was coded in python using Google Colab. The code is pretty densely commented, but here's the general structure:

In Section 1, we download daily OHLCV(open-high-low-close-volume) data for SPY, the ETF that tracks the S&P 500, from Yahoo Finance. We then create numerous extra features that will assist in prediction, including "target", the regime of the next day which we are trying to predict. Finally, we download this new dataset.

In Section 2, we start by using an 80:20 training to testing split on the data. This split is time-based as we are predicting the regime of the following day, so chronologicity is instrumental. The features are then scaled to ensure equal influence. Then, a logistic regression model is trained and tested on the dataset. Its predictions and corresponding probabilities are stored. 

In Section 3, we print a classification report, classification metrics(accuracy, balanced accuracy, precision, recall, F1 score, and ROC-AUC), a confusion matrix, and an ROC curve for the baseline logistic regression model.

In Section 4, we use cross-validation to find the best combination of hyperparameters for the logistic regression model based on ROC-AUC. We create a pipeline in order to handle scaling and avoid data leakage. We then create a parameter grid with all the hyperparameters that will be tested. The grid-search cross-validation is time-based for the same reason as earlier. The tuned logistic regression model is trained and tested on the dataset. Its predictions and corresponding probabilities are stored, and the best hyperparameters and corresponding ROC-AUC is printed.

In Section 5, we print a classification report, classification metrics, a confusion matrix, and an ROC curve for the tuned logistic regression model.

In Section 6, we again use cross-validation to find the best combination of hyperparameters for a random forest model based on ROC-AUC. We do not need a pipeline as scaling is not required for random forest. We create a parameter grid with all the hyperparameters that will be tested. The grid-search cross-validation is again time-based. The (tuned)random forest model is trained and tested on the dataset. Its predictions and corresponding probabilities are stored, and the best hyperparameters and corresponding ROC-AUC is printed.

In Section 7, we print a classification report, classification metrics, a confusion matrix, and an ROC curve for the random forest model.

In Section 8, we create a function that calculates the maximum drawdown in a column/vector containing daily cumulative returns. We then create a backtesting function that uses the testing portion of the dataset and predictions of a model to return performance metrics(total return, annualized return, annualized volatility, sharpe ratio, maximum drawdown) and daily cumulative returns. We then create a function that returns the exact same variables but for the the buy-and-hold strategy.

In Section 9, we print a table containing the classification metrics and trading metrics for the baseline logistic regression model, tuned logistic regression model, random forest model, and buy-and-hold strategy. We also display a chart showing the equity curves for all strategies. Finally, we display a bar graph containing the total returns for all strategies.

Dataset features:
There are 7 original input features including the date. The open feature tracks the opening price for that day. The high feature tracks the highest price of that day. The low feature tracks the lowest price of that day. The close feature tracks the closing price for that day. This is what is most commonly used when referring to the price for a given day. The adjusted close feature tracks the closing price while also accounting for factors like dividends and stock splitting. The volume feature tracks the number of shares traded in a day.
There are 18 extra input features. The return features track the differences between closing prices over 1, 5, 10, and 20-day intervals. They show how SPY’s price changed over various time intervals, which can help the model identify momentum and short-term trends. When features like these that require past data are created, the earliest rows of data are removed as they have missing values.
Moving average features track the mean closing prices over the last 10, 20, 50, and 200 days. They display the recent performance over longer time in- tervals and provide the basis for defining the market regimes. Moving average distance features track the difference between the closing price and moving av- erage divided by the moving average for 50 and 200-day intervals. They show how relatively far away a price is from its recent performance.
Volatility features track the standard deviation of the 1-day returns over the last 10 and 20 days. These features show how much fluctuation is occurring in returns over certain time intervals. The high-low range feature tracks the difference between the high and low prices divided by the closing price. It shows the fluctuation that occurred within one day.
The volume-change feature tracks the change in volume from the previous day. It shows how the number of shares traded has changed since the previous day. The volume moving average feature tracks the mean volume over the last 10 days. It shows the recent performance over a longer interval in terms of how many shares were actually traded. The volume ratio feature tracks the volume divided by the volume moving average. It shows the current performance in comparison to recent performance in terms of volume.
The RSI feature tracks the RSI of the closing prices over a 14-day interval using a custom function. RSI is a momentum indicator. So, this feature shows the speed and strength of recent price changes.
The market regime feature compares the closing price to the 200-day moving average; a price higher than the moving average indicates a bull market and a lower price indicates a bear market. The target variable was the next-day market regime, which allowed the model to use information from the current day to predict whether the following day would be classified as bullish or bearish.

Explanation of models:
Logistic regression is used on a binary variable to predict whether it will be 0 or 1. While it has “regression” in its name and this is a classification problem, logistic regression does not directly predict the label of the variable. Instead, it predicts the probability that the label will be true. The model converts the predicted probability into a class label using a classification threshold, which is typically 0.5.
A random forest involves using hundreds of decision trees to make a more informed prediction by combining their decisions. A single decision tree uses a series of binary questions to arrive at a conclusion. However, a single tree is prone to overfitting; a random forest model combines many decision trees, each trained on a randomly sampled subset of the training data and a random subset of features, reducing overfitting and improving generalization.
